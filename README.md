A modern Full Stack E-Commerce web application built using **Spring Boot**, **React**, and **MySQL**.

SmartCart delivers a complete online shopping experience featuring secure JWT authentication, role-based access control, cloud image storage, PDF invoice generation, responsive UI, email notifications, analytics dashboard, and production-ready deployment.

Designed using enterprise-level architecture and modern development practices, SmartCart demonstrates scalable backend development, responsive frontend engineering, secure REST APIs, and cloud deployment.

# 🏗 Project Architecture

SmartCart follows a modern **three-tier client-server architecture**, separating the presentation layer, business logic, and data layer. The application communicates through secure REST APIs and integrates multiple cloud services for storage, authentication, email delivery, and deployment.

```text
                                    👤 User
                                       │
                                       ▼
                     ┌────────────────────────────────┐
                     │        React Frontend          │
                     │        (Hosted on Vercel)      │
                     └───────────────┬────────────────┘
                                     │
                        HTTPS REST API (Axios)
                                     │
                                     ▼
                  ┌─────────────────────────────────────┐
                  │      Spring Boot Backend            │
                  │       (Hosted on Render)            │
                  └───────────────┬─────────────────────┘
                                  │
          ┌───────────────────────┼────────────────────────┐
          │                       │                        │
          ▼                       ▼                        ▼
 ┌─────────────────┐    ┌────────────────┐      ┌────────────────┐
 │ Spring Security │    │  Cloudinary    │      │  Spring Mail   │
 │ JWT + RBAC      │    │ Image Storage  │      │ Gmail SMTP     │
 └────────┬────────┘    └────────────────┘      └────────────────┘
          │
          ▼
 ┌───────────────────────────────┐
 │ Service Layer (Business Logic)│
 └───────────────┬───────────────┘
                 │
                 ▼
 ┌───────────────────────────────┐
 │ Repository Layer (Spring JPA) │
 └───────────────┬───────────────┘
                 │
                 ▼
 ┌───────────────────────────────┐
 │     MySQL Database            │
 │   (Hosted on Railway)         │
 └───────────────────────────────┘
```

---

## 🏛 Backend Architecture

The backend follows a layered architecture to ensure separation of concerns, maintainability, and scalability.

| Layer | Responsibility |
|--------|----------------|
| 🎮 Controller Layer | Exposes REST API endpoints and handles HTTP requests/responses |
| ⚙ Service Layer | Implements business logic and application workflows |
| 🗄 Repository Layer | Performs database operations using Spring Data JPA |
| 📦 Entity Layer | Represents database tables as Java entities |
| 📄 DTO Layer | Transfers data securely between client and server |
| 🔐 Security Layer | Handles JWT authentication, authorization, BCrypt password encryption, and role-based access control |
| ⚠ Exception Layer | Provides centralized exception handling and custom error responses |
| ☁ Cloud Layer | Manages Cloudinary image uploads and retrieval |
| 📧 Mail Layer | Sends emails using Gmail SMTP integration |



# 🖼 Product Images

SmartCart uses **Cloudinary** for cloud-based image management instead of storing images locally.

### ✨ How it Works

1. 📤 Admin uploads a product image.


2. ☁ Image is securely uploaded to Cloudinary.


3. 🔗 Cloudinary returns a secure image URL.


4. 🗄 The URL is stored in the MySQL database.


5. 🌍 Images are served directly from Cloudinary in both local and production environments.

### ✅ Benefits

- ☁ No local image storage required


- 🚀 Faster image delivery through CDN


- 🌍 Images remain available after deployment


- 📱 Works seamlessly across all devices


- 💾 Reduces backend storage requirements


- 🔒 Secure cloud-hosted media

> **Note:** The `uploads/` folder is no longer required. All product images are stored securely on Cloudinary.

## 🔑 Required Environment Variables

Configure the following properties before running the backend.

```properties
# ===========================
# Application
# ===========================
spring.application.name=smartcart-backend

server.port=8080

# ===========================
# MySQL Database
# ===========================
DB_URL=jdbc:mysql://localhost:3306/smartcart_db

DB_USERNAME=YOUR_DATABASE_USERNAME

DB_PASSWORD=YOUR_DATABASE_PASSWORD

# ===========================
# JWT Authentication
# ===========================
JWT_SECRET=YOUR_JWT_SECRET

JWT_EXPIRATION=86400000

# ===========================
# Gmail SMTP
# ===========================
MAIL_USERNAME=YOUR_GMAIL_ADDRESS

MAIL_PASSWORD=YOUR_GMAIL_APP_PASSWORD

# ===========================
# Cloudinary
# ===========================
CLOUDINARY_CLOUD_NAME=YOUR_CLOUDINARY_CLOUD_NAME

CLOUDINARY_API_KEY=YOUR_CLOUDINARY_API_KEY

CLOUDINARY_API_SECRET=YOUR_CLOUDINARY_API_SECRET
```

---

## 📄 application.properties

The application uses environment variables to keep sensitive information secure.

```properties
spring.application.name=smartcart-backend

spring.datasource.url=${DB_URL}
spring.datasource.username=${DB_USERNAME}
spring.datasource.password=${DB_PASSWORD}

spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true

server.port=${PORT:8080}

jwt.secret=${JWT_SECRET}
jwt.expiration=${JWT_EXPIRATION}

spring.servlet.multipart.enabled=true
spring.servlet.multipart.max-file-size=10MB
spring.servlet.multipart.max-request-size=10MB

spring.mail.host=smtp.gmail.com
spring.mail.port=587

spring.mail.username=${MAIL_USERNAME}
spring.mail.password=${MAIL_PASSWORD}

spring.mail.properties.mail.smtp.auth=true
spring.mail.properties.mail.smtp.starttls.enable=true

cloudinary.cloud-name=${CLOUDINARY_CLOUD_NAME}
cloudinary.api-key=${CLOUDINARY_API_KEY}
cloudinary.api-secret=${CLOUDINARY_API_SECRET}
```
